# 편집기·사진 업로드 검증

## 확인한 공식 자료: 2026-10-10

- [스마트에디터 ONE 기본 인터페이스](https://help.naver.com/service/5593/contents/15507?osType=PC): 본문 확인. 기본·속성 도구 막대와 요소 추가·편집 구조를 안내한다. 게시·임시저장 세부 절차까지 이 문서에서 확인한 것은 아니다. 게시·수정일 미표시.
- [이미지가 안 보이는 경우](https://help.naver.com/service/5593/contents/885?lang=ko&osType=COMMONOS): 본문 확인. 사진 업로더로 등록한 사진과 이미지 복사·붙여넣기의 차이 및 사진 노출 문제를 안내한다. 게시·수정일 미표시.

이 자료는 편집기 기능의 안내이며 자동 게시 허용이나 계정별 이용 정책의 근거는 아니다. 현재 화면·현재 이용 조건을 확인하고 제한을 우회하지 않는다. 공개된 문서로 검증되지 않은 게시 API를 만들어 사용하지 않는다.

브라우저로 직접 실행하는 흐름을 우선한다. 실제 지침·권한에 확인이 필요한 조건이 생기면 SKILL.md의 질문 절차를 사용하고 해당 동작만 보류한다. 최종 제출 승인만 미확정이면 허용된 입력·사진 첨부·임시저장을 먼저 완성하고 미리보기를 보여준다. 자동 입력 자체의 필수 조건이 미해결이면 전송 전에 확인한다. 단순 작업 동의를 플랫폼 허락으로 기록하지 않는다.

## 대상 블로그와 브라우저 접속

- 대상 주소는 대화·작업표에서 먼저 찾는다. 없거나 여러 주소 중 대상이 불분명할 때만 사용자에게 블로그 주소를 묻는다. 계정명으로 주소를 만들어내지 않는다.
- 사용자가 브라우저나 탭을 지정했으면 해당 대상을 사용한다. 지정하지 않았으면 도구의 브라우저 선택 규칙을 따르고, 대상 블로그가 이미 열린 탭은 재사용한다. 적절한 탭이 없으면 새 탭으로 연다. 관계없는 탭을 덮어쓰지 않는다.
- 접속·업로드 준비 요청에는 브라우저를 사용자에게 보이게 열어 진행 상황을 확인할 수 있게 한다. 단순 자료 조사는 백그라운드로 처리할 수 있다. 도구가 화면 표시를 지원하지 않으면 그 한계와 직접 열 수 있는 주소를 알린다.
- 열린 화면의 실제 주소·블로그 표시와 로그인 상태를 확인한다. 로그인·인증이 필요하면 로그인 화면을 띄우고 사용자에게 직접 완료하도록 요청한다. 비밀번호·인증 코드·쿠키·토큰을 채팅이나 작업 파일에 받거나 기록하지 않는다.
- 로그인 후 대상 블로그의 글쓰기 링크로 이동해 편집기가 실제로 열렸는지 확인한다. 다른 계정·블로그로 연결되면 입력 전에 대상을 확인한다. 기존 원고 복구·작성 중인 글 안내가 있으면 이번 작업인지 확인하고 임의로 덮어쓰거나 삭제하지 않는다.
- 접속·화면 확인과 본문 입력·사진 전송·저장·발행을 구분한다. 입력·전송의 지침 조건이 충족되면 직접 실행하고, 미해결인 해당 동작만 보류한다. 기능이 없거나 접근 제한이 나타나면 실제 화면에서 확인한 장애와 완료한 준비를 설명한다.
- 브라우저 도구가 탭 유지 기능을 제공하면 작업을 이어갈 편집기·로그인 탭은 유지한다. 현재 주소, 확인한 로그인 상태, 편집기 도달 여부와 미완료 단계를 작업표에 기록한다. 실제 입력·저장하지 않았다면 완료했다고 보고하지 않는다.

## 입력·사진

브라우저 도구의 파일 업로드 문서를 실제 업로드 전에 읽는다. 네이버 편집기의 보이는 사진 첨부 동작을 사용해 지정된 로컬 파일을 등록한다. Markdown 이미지 링크·외부 이미지 복사만으로 사진 업로드가 끝났다고 하지 않는다.

여러 사진의 자동 정렬을 가정하지 않는다. 첨부 후 배치표 ID·파일과 표시된 사진을 대조한다. 업로드 진행 표시가 끝나고 실제 사진이 표시되는지 확인한다. 실패한 묶음은 기존 첨부 상태부터 확인해 중복을 피한다.

사진 가림 요청은 실제 가림 처리된 파일을 사용한다. 원본을 업로드한 후 가렸다고 주장하지 않는다. 원본을 덮어쓰지 않는다. 사진 가공에 별도 도구가 필요하면 해당 도구의 작업 흐름을 따른다.

## 게시 전후

사용자 검수가 필요하면 실제 미리보기, 대상 블로그, 원고 버전·제목, 사진 수·순서, 공개 범위, 지정 설정과 예약 시각을 보여주고 구체적인 제출 범위를 확인받는다. 이미 이 범위의 승인을 받았고 내용·대상·설정이 달라지지 않았으면 다시 묻지 않는다. 개인정보·파일 전송·최종 동작에 별도 도구 확인 규칙이 있으면 그 규칙을 적용한다. 승인 후 요청된 제출을 직접 수행하고 성공 상태를 확인한다.

검수는 실질적 차이를 확인한다: 제목, 핵심 단락, 소제목, 사진 개수·순서·방향·캡션, 대표 사진, 읽히는 메뉴판, 불필요한 Markdown, 미완성 표시, 협찬 표시, 공개 범위.

발행 버튼 클릭은 완료 증거가 아니다. 성공 메시지·글 URL·실제 표시 내용을 확인한다. 인증 없이 공개 표시를 확인할 수 있는 경우 확인하고, 로그인 화면만 확인했으면 공개 노출을 검증했다고 하지 않는다. 검색 노출·색인 완료는 게시 완료와 별개이며 이 스킬의 성공 조건으로 주장하지 않는다.

예약은 예약 등록 상태와 예정 시각이 성공 근거다. 현재 확인 시각보다 미래에 예정된 작업을 발행 완료로 보고하지 않는다. 임시저장은 확인된 저장 표시·초안 상태를 근거로 보고한다. 기존 글 수정은 요청한 변경이 해당 URL에 반영됐는지 확인한다.

결과 보고에는 작업 모드, 대상 블로그, 제목, 확인한 완료 단계, 실제 URL(있는 경우), 검증 화면(가능한 경우), 미확인 항목을 포함한다. 공개 글을 수정할 때는 기존 원고 상태와 요청 변경을 비교한 뒤 지정된 부분만 수정한다.

## 컴포넌트와 발행 설정

구분선·인용구·스티커의 편집 판단은 writer가 확정한 구성안을 따른다. 위치·역할·스타일을 임의로 추가하거나 재설계하지 않는다. 실제 지원 여부를 확인해 적용하고, 미지원·선택 미확정이면 구성안의 대체·생략 조건을 적용해 차이를 기록한다. 대체 조건이 없고 내용·스타일이 달라지는 변경이 필요하면 사용자에게 확인한다. 임의 구매·외부 이미지 복제는 하지 않는다. 모바일 미리보기에서 구성안과 실제 배치가 일치하는지 확인한다.

원격 자동 입력은 SKILL.md의 플랫폼 허락 조건을 충족한 경우에만 수행한다. 수동 인계도 같은 구성안을 사용한다. `[블록:고유ID | 유형]`과 `[블록:고유ID | 사진:사진ID목록 | 개별/콜라주/슬라이드]`를 순서대로 실제 컴포넌트에 대응한다. 소제목·인용구·구분선·표·링크카드·장소를 현재 화면에서 확인하며 미지원은 일반 문단·목록·텍스트 링크로 대체하고 기록한다. 장소명·주소·지점을 대조한다. 변환 후 내부 표식을 제거하며 본문 텍스트를 잃지 않았는지 확인한다.

[발행 설정 공식 안내](https://help.naver.com/service/5593/contents/15541?lang=ko&osType=PC)(2026-10-10 본문 확인, 게시·수정일 미표시)를 바탕으로 작업표를 구성했다. 주제와 카테고리는 별도 항목이고 태그는 최대 30개 안내를 확인했다. 화면 명칭·지원 여부는 실행 시 재확인한다. 설정별 기본은 건드리지 않음이며 공개 범위만 제출 전 확정한다.
