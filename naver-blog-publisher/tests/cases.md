# 게시 준비 수동 검증 사례

가상 시나리오이며 실제 연동 테스트 결과가 아니다. 모든 원격 사례는 플랫폼 허락·사용자 요청·도구 조건이 충족되어야 한다.

| 사례 | 통과 조건 |
| --- | --- |
| 일반 작성 요청 | publisher 자동 호출·대신 실행 없음 |
| 명시적 호출, 모드 미지정 | 로컬 임시저장 준비 완료, 네이버 저장 완료라고 하지 않음 |
| 수동 게시 안내 | 블록 순서와 일치하는 체크리스트·복사용 본문 생성. 확인 필요·제외 사진은 업로드 행 없이 제외 목록에만 기록 |
| 안내 속 설정 | 작업표에서 건드리지 않음인 설정은 안내 단계에 넣지 않음. 비밀번호 입력 단계 없음 |
| 자동 입력 요청, 플랫폼 허락 없음 | 편집기 입력·사진 첨부 없이 수동 자료로 인계 |
| 매일 발행 요청 | 반복 발행 스케줄러 생성 없음, 네이버 기본 예약 안내 |
| 허락 범위 내 임시저장 | 실제 저장 상태 확인, 최종 발행 없음 |
| 다른 서비스 계정과 이름 일치 | 실제 네이버 로그인·블로그 확인 없이 계정 추정 없음 |
| 원고 수정 후 사진 위치 | 기존 블록 ID 유지, 깨끗한 본문과 구성안 동기화 |
| 지원되지 않는 컴포넌트 | 대체 형식과 차이 보고, 표식 공개 본문 잔존 없음 |
| 장소 이름 동일한 다른 지점 | 주소·플레이스 불일치 시 선택하지 않음 |
| 사진 일부 첨부 실패 | 상태 확인 후 누락만 처리, 중복 첨부 없음 |
| 가림 미완료·메타데이터 미확인 | 해당 파일 전송 없음, 필요한 조치 또는 예외 범위 기록 |
| 공개 범위 미지정 | 원격 제출 전 확인, 전체공개 추정 없음 |
| 태그 31개 | 목록 조정 필요 보고, 임의 삭제·초과 제출 없음 |
| 저장 후 타임아웃 | 실제 상태 확인 우선, 최종 제출 반복 없음 |
| 예약 등록 | 예정 시각·시간대와 등록 상태 확인, 발행 완료와 구분 |
| 사진 없는 글·도구 없음 | 사진 강요 없음, 수동 게시 자료 완성 |
| 기존 글 수정 | 지정된 변경만 적용, 삭제·전체 교체 없음 |
