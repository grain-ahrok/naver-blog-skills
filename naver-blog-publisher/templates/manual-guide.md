# 수동 게시 안내

사람이 네이버 스마트에디터에서 그대로 따라 하는 체크리스트다. [게시 작업표](publish-job.md)와 편집 구성안을 바탕으로 작업마다 새로 만든다. 사용자 작업 폴더의 `outputs/<작업ID>-manual-guide.md`로 저장하고, 같은 폴더에 복사용 깨끗한 본문 `outputs/<작업ID>-body.txt`를 함께 둔다.

작성 규칙:

- 입력 순서 표는 편집 구성안의 블록 순서를 그대로 따른다. 블록 사이 일반 문단은 `본문` 행 하나로 묶고, 복사할 범위를 첫 문장과 끝 문장으로 표시한다.
- 사진은 게시 가능 상태(`가림 불필요·검수 완료 / 가림 완료·검수 완료`)인 파일만 행으로 만든다. 확인 필요·제외 사진은 행 대신 맨 아래 "올리지 않는 사진"에 ID만 적는다.
- 파일은 실제로 열 수 있는 절대 경로로 적는다. 이 안내 자체도 비공개 작업 자료이며 공유할 때는 경로를 지운다.
- 화면 버튼 이름은 편집기 업데이트로 바뀔 수 있으므로 "(화면 명칭 확인)"을 붙이고, 작업표에서 `건드리지 않음`인 설정은 안내에 넣지 않는다.
- 비밀번호·인증 코드를 입력하라는 단계는 쓰지 않는다. 로그인은 사용자가 직접 한다.

## 시작 전

- [ ] 브라우저에서 대상 블로그에 직접 로그인했고, 블로그 이름과 주소가 위와 같다.
- [ ] 글쓰기를 열었을 때 "작성 중인 글" 복구 안내가 뜨면, 그 글이 이번 작업과 관련 없는 경우 덮어쓰지 않고 새 글로 시작한다.
- [ ] 사진 폴더를 탐색기(Finder)에서 열어 두었다.

## 입력 순서

| ✓ | 순서 | 블록 | 할 일 | 넣을 내용 / 파일 | 확인할 것 |
| --- | --- | --- | --- | --- | --- |
| [ ] | 1 | 제목 | 제목 칸에 붙여넣기 | (확정 제목) | 오타·잘림 없음 |
| [ ] | 2 | 협찬 표시 | 본문 맨 앞 첫 문단으로 붙여넣기 | (협찬 문구, 해당 시) | 사진 속 문구만으로 대신하지 않음 |
| [ ] | 3 | 본문 | 복사용 본문에서 해당 범위 붙여넣기 | "첫 문장…" ~ "…끝 문장" | 서식이 따라오면 서식 없이 붙여넣기 |
| [ ] | 4 | B01 소제목 | 텍스트 스타일에서 소제목 선택 후 입력(화면 명칭 확인) | (소제목 텍스트) | 일반 글씨로 남지 않음 |
| [ ] | 5 | B02 사진 | 사진 버튼으로 업로드 후 레이아웃 선택 | P03 `(절대 경로)`, P04 `(절대 경로)` / 콜라주 | 장수·순서·방향, 작은 글씨 가독성 |
| [ ] | 6 | B03 캡션 | 사진 아래 설명 칸에 입력 | (캡션) | 사진에 보이는 사실과 일치 |
| [ ] | 7 | B04 장소 | 장소 버튼에서 검색 후 선택(화면 명칭 확인) | 검색어: (장소명) / 대조: (주소) | 지점·주소 일치, 이름 비슷한 다른 지점 아님 |

필요한 만큼 행을 늘린다. 인용구·구분선·표·링크카드도 같은 형식으로 쓰고, 편집기에 해당 기능이 없으면 구성안에 기록된 대체 방법(일반 문단·목록·텍스트 링크)을 적는다.

## 입력 후 점검

- [ ] `[블록:…]` 같은 내부 표시나 Markdown 기호(`#`, `**`, `|`)가 본문에 남지 않았다.
- [ ] 사진 총 ( )장, 순서가 위 표와 같고 같은 사진이 두 번 들어가지 않았다.
- [ ] 가림 처리된 사진이 원본이 아니라 게시용 사본이다(가린 부분이 실제로 보이지 않음).
- [ ] 대표 사진: (지정 시 사진 ID) / 지정하지 않았으면 그대로 둔다.
- [ ] 모바일 미리보기에서 메뉴판 가격과 콜라주 속 글씨가 읽힌다.

## 저장 또는 발행 설정

작업표에서 지정한 값만 바꾼다. 아래에 없는 설정은 손대지 않는다.

- [ ] 임시저장만: 저장 버튼(화면 명칭 확인) → 저장 완료 표시 확인 → 여기서 끝
- [ ] 발행 버튼을 눌러 설정 창 열기
  - [ ] 카테고리: ( )
  - [ ] 주제: ( )
  - [ ] 공개 범위: ( )
  - [ ] 태그: ( ) — 최대 30개
  - [ ] 예약: (날짜·시각·시간대, 해당 시)
- [ ] 마지막으로 제목·공개 범위를 한 번 더 확인하고 직접 발행(또는 예약)

## 끝난 뒤

- [ ] 발행: 글 주소를 복사하고, 로그아웃 상태나 모바일에서 사진 순서와 협찬 표시를 확인한다.
- [ ] 예약: 예약 목록에서 예정 시각을 확인한다. 아직 발행된 것은 아니다.
- [ ] 결과를 알려주면 기록에 남긴다. 예: `발행했어, 주소는 https://blog.naver.com/...` 또는 `임시저장까지 했어`
- [ ] 발행 버튼을 눌렀는데 응답이 없으면 **다시 누르지 말고** 내 블로그 글 목록부터 확인한다.
