# 게시 작업표

비공개 작업 자료다. 자체로 사용자 권한이나 플랫폼 허락을 만들지 않는다. 비밀번호·쿠키·토큰을 기록하지 않는다.

- 작업 ID / 원고 버전:
- 대상 블로그 / 실제 확인한 로그인 계정:
- 대상 주소 확인 출처(대화·기존 작업표·사용자 답변):
- 브라우저·탭 / 사용자에게 화면 표시 여부 / 현재 확인한 주소:
- 로그인 상태 / 글쓰기 화면 도달 여부 / 기존 작성 중인 글 여부:
- 실행 경로: 브라우저 직접 실행(우선) / 수동 인계(사유 기록)
- 목표 단계: 검수용 임시저장(게시 준비 기본) / 발행 / 예약 / 기존 글 수정
- 사용자 검수·승인: 기존 승인 범위 / 미리보기·설정 확인 자료 / 추가 확인이 필요한 조건 / 답변
- 사용자 요청 범위 / 플랫폼 자동화 허락 근거·수단·범위(원격 자동 실행 시):
- 근거 상태: 미확인 / 허용 범위 확인 / 해당 방식 제한 확인
- 확인한 공식 출처·확인일 / 조항과 적용 해석:
- 사용자에게 묻는 내용 / 필요한 자료 / 받은 답변(자격증명 제외):
- 답변 대기 중 완료한 준비 / 보류하는 자동 입력·전송 단계:
- 확정 제목 / 깨끗한 본문 / 편집 구성안 파일:
- 카테고리 / 주제: 건드리지 않음(기본) 또는 지정 값
- 공개 범위: 미지정(제출 전 확정) / 전체공개 / 이웃공개 / 서로이웃공개 / 비공개
- 댓글 / 공감 / 검색 허용 / 블로그·카페 보내기 / 외부 공유·보내기 / CCL: 각각 건드리지 않음(기본) 또는 지정 값
- 태그: 건드리지 않음 또는 확정 목록(현재 안내 최대 30개, 실제 화면 재확인)
- 공지사항 등록 / 대표 사진: 건드리지 않음 또는 지정 값
- 예약 시각·시간대 / 기존 글 URL·수정 범위(해당 시):
- 협찬·개인정보 검수 / 미해결 사항:

## 사진

- 제공 사진 수 / 사용 사진 수 / 제외 사진 ID·사유·사용자 확인:
- 가로 묶음: 블록 ID / 왼쪽부터 사진 ID 순서 / 열 수 / 잘림 허용 범위 / 모바일 확인 결과:
- 네이버 편집기 사용: 원본 전송 승인 범위 / 사진별 최소 가림 위치 / 적용한 도구 / 편집 후 검수 결과:
- 로컬 편집을 선택한 경우: 사용자 선택 근거 / 원본 보존 / 게시용 사본 경로:

| 사진 ID | 게시용 파일 절대 경로 | 편집 블록 ID·레이아웃 | 캡션 | 검수 상태 | 메타데이터 상태·예외 허용 |
| --- | --- | --- | --- | --- | --- |

검수: 가림 불필요·검수 완료 / 가림 완료·검수 완료 / 확인 필요 / 제외.
메타데이터: 위험 항목 없음 확인 / 제거 확인 / 미확인. 사진이 없으면 사진 없음.

네이버 편집 예정 원본은 전송 승인을 확인해도 편집·검수가 끝나기 전까지 `확인 필요`로 둔다. 공개 게시 전에는 완료 상태를 확인한다.

## 네이버 내돈내산 기능

- 직접 결제 여부 / 리뷰 대가·협찬·기타 수익형 요소 여부:
- 지원 서비스의 실제 해당 이용내역 조회 결과 / 제외 조건 확인:
- 이용안내·다른 네이버 서비스 노출 조건 확인 / 동의가 필요한 경우 사용자 답변:
- 첨부 결과 / 이용내역 미조회·미지원 등 미첨부 사유 / 본문 직접 결제 표현:

직접 결제만으로 기능 이용 가능 여부를 확정하지 않는다. 이용내역·계정 식별자 등 비공개 정보는 게시 본문에 넣지 않는다.
