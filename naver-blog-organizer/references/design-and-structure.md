# 일상·리뷰 블로그 기본 설계와 사례

확인일: 2026-10-11. 아래 사례는 브라우저에서 실제 PC 홈의 카테고리와 글 목록, 화면 디자인을 확인했다. 모바일 화면과 관리자 설정, 유입 통계는 확인하지 않았다. 두 블로그는 확인 당시 네이버 이달의 블로그 2026년 9월 목록에 소개되어 있었다. 과거 파워블로그 수상 여부는 확인하지 않았다.

## 사례와 적용 판단

### 오늘 살림 — Lajuuhome
https://blog.naver.com/imlajuu

관찰: 밝은 크림 계열 바탕, 집 안의 자연광 사진을 활용한 넓은 타이틀, 정사각형 사진 중심의 글 목록이다. 상단 메뉴에 살림·정리수납·청소·집꾸미기를 배치한다. HOME 아래 살림 관련 분류를 모으고 구분선 아래 일상·음식요리·가족육아를 둔다. 공지 영역에는 대표 생활 콘텐츠가 보인다.

해석: 사진과 배경의 분위기를 맞추고 핵심 주제를 홈·메뉴·소개에서 반복하여 블로그의 성격을 전달한다. 일상 기록도 같은 공간에 담되 핵심 콘텐츠와 구분한다.

적용: 본인의 일상 사진 한 장으로 타이틀을 만들고, 자주 쓰는 리뷰 분야를 상단 메뉴에 노출한다. 이 사례의 큰 타이틀과 위젯 규모는 그대로 복제할 필요가 없다. 본문 접근이 쉬운지 별도로 판단한다.

### 문화를 사랑한 고양이 — 초롱집사
https://blog.naver.com/puccajunior

관찰: 회색 외곽과 밝은 글 영역, 사진 중심의 목록, 왼쪽 프로필·카테고리 구조이다. 문화생활 아래 전시회·음악회가 있고 미술서적·고양이·일상기록·문득 떠오른 생각들도 구분되어 있다. 소개에는 전시·아기·고양이와 일상이 함께 명시되어 있다.

해석: 리뷰 대상에 따른 계층과 개인 기록 영역을 함께 유지하여 전문 관심사와 생활 기록을 연결한다.

적용: 큰 주제 아래 필요한 세부 리뷰를 묶고, 날짜별 일상은 별도 영역에 둔다. 작은 블로그라면 사례처럼 많은 글에 맞춘 분류를 처음부터 복제하지 않는다.

## 권장 기본안 — 공식 규격이 아닌 디자인 제안

| 요소 | 시작안 | 이유 |
|---|---|---|
| 전체 바탕 | #F7F5F0 밝은 아이보리 | 다양한 일상 사진과 조화 |
| 글 영역 | #FFFFFF | 긴 글의 가독성 |
| 글자 | #272727 | 밝은 바탕에서 선명하게 |
| 포인트 | #6F806D 차분한 녹색 | 메뉴·짧은 표시 등에 제한 사용 |
| 타이틀 | 직접 찍은 일상 사진 한 장 + 블로그명 + 소개 한 줄 | 첫 방문자가 주제를 이해 |
| 소개 문구 예시 | 직접 써보고, 먹어보고, 다녀온 일상 기록 | 리뷰의 경험 중심 성격 전달 |
| 썸네일 | 실제 대상 사진, 일관된 구도, 글자는 필요할 때 짧게 | 작은 화면에서도 대상 식별 |

이미지 크기는 업로드할 때 현재 네이버 안내와 미리보기를 확인한다. 본문 뒤의 강한 무늬, 긴 배너 문구, 불필요한 위젯은 줄인다. 네이버 기본 기능으로 먼저 만들고 커스텀 위젯은 필요한 동선이 있을 때 선택한다.

## 시작 카테고리

아래는 선택 가능한 기본 구조다. 각 하위 분류에 글이 적으면 상위만 먼저 사용한다.

```text
블로그 안내
일상 기록
  하루·주간 기록
  생각·취미
맛집·카페
  맛집
  카페·디저트
제품 사용기
  생활용품
  디지털·가전
여행·나들이
  여행
  동네·전시·체험
```

뷰티·패션 리뷰가 많으면 제품 사용기의 하위 분류 또는 독립 상위로 조정한다. 지역별 구분은 지역 글이 충분히 쌓이고 방문자가 지역별로 찾을 필요가 있을 때 도입한다. 글마다 카테고리는 핵심 목적에 따라 정하고 지역·기간·브랜드는 제목이나 본문 정보에 담는다.

협찬/내돈내산은 주제와 다른 분류 축이므로 기본 카테고리를 쪼개는 기준으로 쓰지 않는다. 실제 경제적 관계를 정확히 표시하며 내돈내산 표현도 사실일 때만 사용한다.

## 글 형식과 관리

- 일상: 시점 → 오늘의 장면 → 경험·생각 → 관련 기록.
- 맛집·카페: 방문 시점·관계 표시 → 위치와 방문 정보 → 주문·가격 → 실제 느낌·장단점 → 재방문 판단.
- 제품: 구매/제공 여부·사용 기간 → 선택 이유 → 실제 사용 → 장단점 → 추천 대상.
- 여행·체험: 방문 시점 → 동선·비용 → 실제 경험 → 유용한 정보 → 관련 장소 링크.

가격·운영 시간 등은 확인 시점을 표시하고 확인되지 않은 항목을 채우지 않는다. 제목 예시: `성수 ○○카페 방문 후기｜주문 메뉴와 좌석`, `○○ 텀블러 한 달 사용기｜세척과 휴대성`, `10월 둘째 주 일상｜산책과 집밥`. 기간이나 경험은 실제일 때만 사용한다.

홈 진입은 블로그 소개·대표 리뷰·최근 글로, 글 진입은 관련 리뷰와 카테고리 모음글로 이어지게 설계한다. 공지나 대표 영역의 사용 가능 여부는 현재 PC·모바일 기능으로 확인한다. 날짜별 분류 대신 주간·월간 일상 글 제목을 활용한다.

매월: 미분류 글 배정, 비슷한 분류 검토, 모음글 링크 보완, 정보 업데이트. 카테고리의 숫자보다 찾기 쉬움과 계속 쓸 수 있는지를 기준으로 판단한다.

## 플랫폼 근거 — 적용 전 재확인

네이버 공식 카테고리 안내: https://help.naver.com/service/5593/contents/15233?lang=ko&osType=PC

확인 당시 PC에서 관리 > 메뉴·글·동영상 관리 > 메뉴 관리 > 블로그 또는 카테고리 영역 EDIT로 수정 가능하다. 카테고리는 2단까지 구성할 수 있다. 이름에 이모티콘을 설정할 수 없고 카테고리는 프롤로그에 노출되지 않는다고 안내한다. 삭제하면 예약 글을 포함한 소속 글도 삭제된다고 명시한다. 따라서 카테고리 통합은 글 이동과 이름 변경을 우선한다.

꾸미기 공식 안내 목록: https://help.naver.com/service/5593/category/3103?lang=ko

스킨·타이틀·글 영역 넓이·레이아웃 등의 항목에서 최신 경로를 확인한다. 모바일 커버와 홈은 모바일 화면에서 별도로 확인한다. PC 사진·카테고리 분석 결과를 모바일 관찰 결과로 표시하지 않는다.
