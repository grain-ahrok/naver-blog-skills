# 키워드 분석

핵심 명칭과 지역·이용 목적·비교 조건을 조합해 후보를 만든다. 기본 기간은 최근 12개월로 제안하되 실제 자료의 날짜 범위를 우선한다.

## 데이터별 해석

- 데이터랩: ratio는 조회 범위에서 정규화된 상대 검색 추이다. 월간 실제 횟수로 바꾸지 않는다. 검색어 묶음, 기간, 시간 단위, 기기·연령·성별 조건을 함께 기록한다. 별도 요청에서 정규화된 값은 같은 기준이 확인되지 않으면 직접 비교하지 않는다.
- 검색광고: 제공된 월간 검색수·클릭수·클릭률과 PC·모바일 구분을 그대로 사용한다. 광고 경쟁도와 클릭률을 블로그 경쟁도·클릭률로 대체하지 않는다. `<10` 같은 표시는 그대로 보존한다.
- 실제 검색 결과: 독자의 질문, 콘텐츠 종류, 제목·구성, 누락된 정보를 관찰한다. 상위 노출의 원인을 단정하지 않는다.

공식 API가 설정되어 있고 사용 권한이 확인되면 활용한다. 데이터랩 API는 환경 변수 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`이 있을 때만 사용하며 값을 출력하지 않는다. 없으면 자료 파일·화면·수동 입력으로 분석한다. 검색광고 키워드 도구는 사용자가 내려받은 파일을 기본 입력으로 한다. API 키는 채팅이나 저장소에 넣지 않는다. 자료 접근을 위해 광고그룹 생성이나 광고비 지출을 수행하지 않는다.

| 키워드 | 데이터 출처·기간·조건 | 수요 지표·단위 | 추세 | 검색 의도 | 추천·이유 | 미확인 항목 |
| --- | --- | --- | --- | --- | --- | --- |

추천은 실제 경험과 독자 질문의 일치, 보유 사진, 차별 정보, 관측된 수요를 근거로 한다. 후보 3~5개는 소재에 맞는 경우에만 제안한다. 계절성은 반복 기간 자료가 있을 때 해석하고, 단기간의 상승을 계절성으로 확정하지 않는다. 데이터가 없으면 수요·추세는 미확인이고 추천은 검증할 가설이다.

근거: [데이터랩 공식 설명](https://developers.naver.com/docs/serviceapi/datalab/search/search.md), [키워드 도구 안내](https://ads.naver.com/help/faq/1406).

## 검색 화면 관찰

가능한 화면에서 스마트블록의 주제·배치, 자동완성·연관검색어, 플레이스 리뷰와 블로그 리뷰 구분, 인플루언서 영역을 기록한다. 보이지 않은 항목은 미관찰로 남기며 관찰된 구조를 검색 의도의 가설로 사용한다. 로그인·기기·시각 조건을 기록하고 순위 원인이나 보장으로 설명하지 않는다. 네이버의 사전 허락 없는 자동 검색·수집을 수행하지 않고 사용자 제공 화면·자료 또는 허용된 API와 조사 수단을 사용한다. [이용약관](https://policy.naver.com/policy/service.html)과 현재 수단의 허용 범위를 확인한다. 숨김 키워드·무관한 반복 삽입을 추천하지 않는다.
