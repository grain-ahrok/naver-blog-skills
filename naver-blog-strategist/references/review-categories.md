# 카테고리와 검색 의도

아래는 독자 질문을 고르기 위한 설계 기준이다. 모든 항목을 글에 강제로 넣거나 검색 알고리즘의 공식 기준으로 설명하지 않는다.

| 분류 | 핵심 질문 | 의도에 따른 우선순위 |
| --- | --- | --- |
| 카페 | 메뉴·가격, 분위기, 좌석, 접근성 | 작업: 콘센트·소음·좌석 / 데이트: 대화 환경·디저트 / 대형 카페: 주차·공간 |
| 음식점 | 주문 메뉴·가격, 맛·양, 예약·웨이팅, 재방문 | 가족: 좌석·동선 / 가성비: 지불 금액·양 / 술집: 안주·대화 환경 |
| 여행 | 이동·일정·비용·동선 | 당일치기: 이동 시간 / 가족: 쉬는 곳·접근성 |
| 숙소 | 객실 유형·가격·청결·시설·서비스 | 휴식: 소음·침구 / 가족: 객실 동선·시설 |
| 제품 | 모델·구매 목적·가격·사용 기간·환경·장단점 | 비교: 같은 조건의 차이 / 장기 사용: 변화·고장·관리 |
| 서비스 | 예약·비용·과정·시간·응대·재이용 | 첫 이용: 절차 / 비교: 포함 범위·추가 비용 |
| 기타 | 소재에 따라 독자가 결정할 질문 | 실제 경험으로 답할 수 있는 핵심 질문부터 설계 |

복합 소재는 주·보조 분류를 기록한다. 외부 원문의 정보를 작성자 경험으로 바꾸지 않는다. 사실이 없는 항목은 질문·누락으로 남긴다.

## 민감 분야

병원·시술은 광고 해당 여부·치료 효과 경험 표현·심의 검토를 우선한다. 식품·건강기능식품은 질병 예방·치료 주장과 인정 기능성을 구분한다. 화장품은 의약품 오인 표현·기능성 근거를 확인한다. 부정적 리뷰는 방문 시점·증거·공익과 개인 식별 위험을 검토한다. 법적 검토가 미해결인 소재를 일반 리뷰 전략으로 확정하지 않고 작성 단계에 확인 사항을 전달한다. 세부 규정은 현행 공식 자료로 확인하며 개인 경험 전체가 일률적으로 위법하다고 판정하지 않는다.
