# 출처 조사와 확인 기록

공식 자료 → 실제 검색 결과·원문 → 공개 실무 사례·유튜브 순으로 사용한다. 자료마다 제목, URL, 게시·수정일(없으면 미표시), 확인일, 읽은 범위, 적용할 주장과 한계를 기록한다. 영상은 제목·채널·발행일·타임스탬프와 실제 확인한 자막 또는 내용을 기록한다. 설명만 읽었으면 시청했다고 하지 않는다.

개인 계정·영상 채널 등 식별 가능한 실제 조사 기록은 비공개 결과에 보관한다. 배포용 스킬 문서에는 기관 공식 문서 링크와 일반 조사 방법만 넣으며, 공유용 결과는 익명 표본 ID를 사용한다. 비공개 원문과 공개 요약을 혼동하지 않는다.

## 조사 시작점: 본문 미확인, 주장 근거로 사용하지 않음

| 자료 | URL | 확인 상태 |
| --- | --- | --- |
| 게시글 통계 | https://help.naver.com/service/5593/contents/15314 | 제목·메뉴만 확인. 본문 미확인 |
| 유입 분석 | https://help.naver.com/service/5593/contents/15330 | 제목·메뉴만 확인. 본문 미확인 |
| D.I.A. 소개 | https://help.naver.com/service/5626/contents/22926 | 제목·메뉴만 확인. 본문 미확인 |
| C-RANK 소개 | https://help.naver.com/service/5626/contents/22927 | 제목·메뉴만 확인. 본문 미확인 |

현재 요청에 필요한 자료를 다시 열어 확인한다. 고객센터 본문이 읽히지 않으면 해당 주장에 근거로 인용하지 않는다. 접근 실패는 기록하고 사용자 제공 자료로 가능한 분석을 이어간다. 알고리즘 소개를 현재 가중치나 상위 노출 보장으로 해석하지 않는다.

검색 결과에는 검색어, 확인 시각, 화면의 검색 영역, 기기·로그인 조건 중 관찰 가능한 것을 기록한다. 실제 읽은 게시물만 비교한다. 다른 검색엔진 결과를 네이버 현재 순위로 표시하지 않는다. 외부 사례의 효과는 독립적으로 입증되지 않았다면 경험적 주장으로 표시한다.
