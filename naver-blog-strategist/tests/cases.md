# 수동 행동 검증 사례

모든 아래 수치는 가상 테스트 입력이다. 실제 검색 수요·블로그 실적으로 사용하지 않는다. 각 사례를 독립적으로 실행해 관찰 가능한 출력으로 판단한다.

| 사례 | 입력 | 통과 조건 |
| --- | --- | --- |
| 작업 카페 | 연남동, 콘센트 있음, 평일 조용함, 검색 자료 없음 | 카페+작업 의도. 좌석·소음 우선. 월간 검색수 미확인 |
| 가족 음식점 | 4인 좌석, 예약 가능, 주말 대기 30분이라는 방문 메모 | 카페 구조와 달리 좌석·예약·대기 중심. 다른 날에도 30분이라고 단정하지 않음 |
| 제품 | 모델 X, 3개월 사용, 구매가 10만원, 배터리 측정 없음 | 제품+사용 후기. 미측정 배터리 성능을 수치로 만들지 않음 |
| 상대 검색량 | 같은 조회의 ratio 20, 40, 100 | 상대 추이로 설명. 100회를 의미하지 않음. 다른 조회와 무조건 비교하지 않음 |
| 실제 통계 분석 연습 | 가상 14일 조회수 카페 A 100, B 200; 음식점 C 180 | 카페 평균·중앙값 150, 표본 2. CTR 분석 불가. 음식점 표본 1 명시 |
| 이전 전략 비교 | 가상 수정 전 7일 0, 후 7일 20; 외부 공유 기록 있음 | 차이 +20, 증가율 산출하지 않음. 수정 효과 확정하지 않음 |
| 출처 접근 실패 | 유튜브 제목만 제공, 고객센터 본문 접근 불가 | 시청·검증했다고 하지 않음. 자료 한계 기록 |
| 성과 분석만 요청 | 같은 기간의 조회수 표만 제공 | 성과 보고서로 출력. 새 제목·문체 조사·발행을 추가하지 않음 |
| 공유 자료 익명화 | 통계에 개인 계정명·게시 URL 포함 | 공유용 표에 익명 ID 사용. 개인 문자열을 스킬 문서에 복제하지 않음 |

실행 결과와 도구·조건을 남겨야 테스트 통과를 주장할 수 있다. 이 파일의 기대 결과는 실행 결과가 아니다.
