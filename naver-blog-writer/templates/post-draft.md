# 작성 결과

## 문체와 구성

- 사용 자료 / 미확인 항목:
- 문체 설정과 근거 / 참고 글 읽은 범위:
- 제목 후보(기본 3개, 확정 제목이 있으면 생략) / 선택 제목:
- 원고 ID·버전 / 상태: 초안·확인 필요·게시 준비 완료

## 게시용 본문

실제 경험으로 도입하고 독자가 궁금해할 정보 순서대로 작성한다. 소제목 아래에서 관련 사진을 설명한다. 장점·아쉬운 점과 적합한 이용 대상을 확인된 사실로 정리한다. 협찬·제휴 표시가 필요하면 게시 본문에 포함한다. 관련 해시태그는 필요한 것만 별도로 제공한다.

## 편집 구성안: 본문과 별도

[컴포넌트 규격](../references/editor-components.md)에 따라 같은 본문에 고유 블록 ID·사진 레이아웃·장소·표 등을 표시한다. 공개 본문에는 표식을 넣지 않는다. 본문과 구성안의 버전을 함께 갱신한다.

## 사진 배치표: 본문과 별도

| 사진 ID | 게시용 파일 절대 경로 | 편집 블록 ID·레이아웃 | 역할·캡션 | 검수 상태 | 메타데이터 상태 |
| --- | --- | --- | --- | --- | --- |

검수 상태: 가림 불필요·검수 완료 / 가림 완료·검수 완료 / 확인 필요 / 제외. 메타데이터 상태: 위험 항목 없음 확인 / 제거 확인 / 미확인. 사진이 없으면 표 대신 사진 없음으로 기록한다. 공개·공유용 보고서에는 개인 경로를 포함하지 않고 비공개 게시 작업표에만 절대 경로를 남긴다.

## 게시 전 확인: 본문과 별도

- 확인이 필요한 가격·시간·경험:
- 필요한 추가 사진 / 사용 권한·개인정보:
- 본문 식별 정보 생략·일반화 / 사진 블러·마스킹 / 메타데이터 확인 상태:
- 게시 스킬에 전달할 검수 완료 사본 / 제외한 사진 / 남은 확인 사항:
- 외부 정보 출처와 확인 날짜:
- 협찬·제휴·직접 결제 여부:
- 원고 작성 / 임시저장 / 실제 게시 중 완료한 상태:
