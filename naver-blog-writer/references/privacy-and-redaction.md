# 개인정보 검수와 게시용 사진 가림

작성 시 이 지침을 읽고 본문·사진·캡션·해시태그·파일명을 함께 확인한다. 사용자가 공개하려는 정보와 리뷰에 불필요한 식별 정보를 구분한다. 개인정보를 발견했다는 이유로 원고 전체를 중단하지 말고, 불필요한 정보는 제외·일반화한 원고를 먼저 완성한다.

## 공개 기준

| 대상 | 기본 처리 |
| --- | --- |
| 가게의 공개 주소·대표 전화·공식 메뉴 | 리뷰에 필요하면 유지. 개인 연락처와 구분 |
| 작성자·동행인의 실명·개인 연락처·집 주소 | 리뷰에 불필요하면 생략·일반화. 공개가 필요한 경우 사용자 지정 범위 확인 |
| 주변 손님·직원·어린이의 식별 가능한 얼굴 | 식별이 필요하지 않으면 가림 또는 사진 제외. 출입 가능한 장소라는 이유만으로 공개 동의를 추정하지 않음 |
| 차량번호·명찰·택배 송장·예약·주문·영수증 번호 | 식별 영역 가림. 가격·메뉴처럼 필요한 정보는 유지 |
| 카드·계좌·신분증·비밀번호·토큰·쿠키 | 원고·캡션·로그에서 제외하고 사진에서는 식별 영역 제거 |
| 영수증·티켓·화면의 QR·바코드 | 확인되지 않은 내용도 식별·조회 가능성을 고려해 해당 영역 전체 가림 |
| 집 위치·숙소 객실번호·실시간 이동 정보 | 필요한 지역 수준으로 일반화하고 불필요한 정확한 위치·현재 일정은 제외 |
| 회사 화면·문서·알림·개인 대화 | 사적인 내용·직원명·내부 정보 제외. 식별이 어려우면 사진 제외 |

단순히 이름을 지웠어도 직장·역할·동행 관계·정확한 시간·위치의 조합으로 식별되는지 확인한다. 공개된 사업장 정보까지 일괄 삭제하지 않는다. 검수 보고서에 민감한 원문을 그대로 재인용하지 말고 `연락처 가림 필요`처럼 정보 종류만 기록한다.

## 자동 가림 작업

원고·사진 준비 요청 안에서 필요한 게시용 사본의 가림은 수행할 수 있다. 원본 삭제·덮어쓰기와 외부 업로드까지 승인된 것으로 해석하지 않는다. 사용자가 영역이나 방식을 지정하면 우선한다.

1. 실제 사진을 열고 가릴 대상을 찾는다. 지원되는 얼굴·문자 감지 도구가 있으면 후보 영역 탐지에 보조적으로 사용하되 모든 개인정보를 자동 감지했다고 단정하지 않는다. 탐지 결과와 사진 전체를 함께 확인한다.
2. 가능한 경우 로컬 이미지 처리 도구로 원본 크기 기준의 정확한 영역을 편집한다. 도구·좌표 API는 제공된 문서를 따른다. 환경에서 이미지 편집 도구 사용이 지정되어 있으면 그 도구를 사용한다. 외부 처리 서비스에 원본을 보낼 경우 민감한 사진 전송에 필요한 승인을 먼저 받는다. 로컬 도구가 없다는 이유로 자동 업로드하지 않는다.
3. 얼굴·차량번호에는 충분한 블러 또는 불투명 마스킹을 적용한다. 민감한 숫자·문자·QR·바코드는 기본적으로 불투명 마스킹이나 잘라내기를 사용한다. 가벼운 블러·픽셀화만으로 읽을 수 없다고 보장하지 않는다. 경계 여백을 포함해 전체 영역을 가린다.
4. `outputs/redacted/`에 원본과 다른 게시용 파일을 만든다. 예: `P01-redacted.jpg`. 얼굴 여러 개, 거울·창문 반사, 배경 화면, 영수증 구석 등도 확인한다. 메뉴·가격·제품 외형 등 리뷰 정보가 불필요하게 바뀌지 않게 한다.
5. 게시용 파일의 EXIF 위치 정보 등 불필요한 메타데이터를 지원 도구로 검사하고 필요한 항목을 제거한다. 상태를 `위험 항목 없음 확인 / 제거 확인 / 미확인`으로 기록한다. 미확인 파일은 사용자가 그 한계를 알고 해당 파일 업로드를 명시적으로 허용했을 때만 예외로 전달하며, 없으면 해당 사진은 확인 필요다. 파일명에 실명·연락처·정확한 주소가 있으면 중립적인 ID로 바꾼다. 플랫폼이 자동 제거할 것이라고 가정하지 않는다.
6. 가공 결과를 다시 열어 전체 화면과 해당 영역 확대에서 읽힘·식별 여부, 누락, 과도한 변형을 검수한다. 생성형 편집이면 다른 영역의 글자·메뉴·외형 변화도 대조한다. 가림 실패나 정보 변형이 있으면 수정하고, 해결되지 않으면 해당 사진을 게시 자료에서 제외한다.
7. 배치표의 경로를 검수한 사본으로 갱신한다. 가림 대상 종류·방식·검수 결과만 기록한다. 미확인 메타데이터나 가림 여부는 확인 완료로 표시하지 않는다. 원본을 대신 업로드하는 대체 동작은 하지 않는다.

사진 편집 도구가 없으면 가림할 영역과 필요한 작업을 명시하고 원고 작업을 계속한다. 가림이 필요한 원본은 게시 가능 자료로 전달하지 않는다. 개인정보 검수는 실제 사진을 확인한 범위에 한하며 법적 준수를 보장하는 인증이 아니다.

## 스킬 간 인계

게시 스킬에는 확정 본문, 검수한 게시용 파일 경로, 메타데이터 상태, 공개 허용 범위, 남은 확인 사항을 전달한다. 가림이 필요한 원본은 게시 사진 목록에 포함하지 않는다. 가림이 불필요하고 검수된 원본은 사용할 수 있다. 결과 경로는 사용자 작업 폴더 기준이며 설치된 스킬 폴더에 사진을 저장하지 않는다. 개인정보가 포함된 통계·원고·가공 사진·검수 화면은 공개 저장소에서 제외하며 `.gitignore`만으로 기존 추적 파일까지 보호된다고 가정하지 않는다.
