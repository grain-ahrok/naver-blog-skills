# 구분선·인용구·스티커 사용 기준

글을 꾸미거나 참고 블로그의 편집 구성을 분석할 때 읽는다. 아래 기준은 가독성과 문체를 위한 편집 제안이며 검색 순위·체류 시간 상승을 입증한 공식이 아니다. 사용자 취향과 기존 스타일을 우선한다.

## 참고 글 조사

사용자가 지정한 글을 우선한다. 지정 글이 없으면 같은 소재의 서로 다른 작성자 공개 네이버 글 3~5편을 시작 표본으로 삼는다. [문체 조사](voice-and-style.md)와 같은 표본을 재사용한다. 인플루언서 여부는 공식 프로필 등으로 확인하며 검색 순서·공감 수만으로 인기나 성과를 단정하지 않는다.

본문에서 요소의 위치·역할·앞뒤 문단을 기록한다. 구분선 컴포넌트와 문자로 그린 선, 인용구 서식과 실제 타인의 발언, 스티커와 이모지·사진 속 캐릭터를 구분한다. 본문만 읽혔으면 색·크기·움직임을 관찰했다고 하지 않는다. 화면이나 렌더링된 본문 요소를 확인하고, 접근하지 못한 부분은 미확인으로 기록한다. 출처·게시일·확인일·읽은 범위는 비공개 작업 보고서에만 남기고 배포 문서에는 개인 계정·글 제목을 넣지 않는다.

2026-10-11 공개 카페 후기 세 편을 확인한 범위에서는 사진·설명·지도·표 중심의 구성, 인용구 서식을 소제목으로 반복하고 끝에 스티커를 배치한 구성, 문자 선으로 구간을 나눈 구성이 각각 있었다. 일부 표본의 전체 렌더링은 확인하지 못했으므로 전체 장식 수나 공통 사용 비율은 산출하지 않았다. 이 작은 표본으로 어느 방식이 성과가 좋다고 결론 내리지 않는다. 아래 권장 횟수는 표본 통계가 아닌 시작안이다.

## 언제, 어떻게 사용할까

| 요소 | 넣기 좋은 위치·목적 | 사용 방법 | 생략하거나 줄일 경우 |
| --- | --- | --- | --- |
| 구분선 | 방문 정보에서 경험으로, 후기에서 최종 요약으로 넘어가는 큰 전환 | 짧은 리뷰는 0~2개부터 검토. 한 가지 단순한 선 스타일을 유지하고 앞뒤 여백 확인 | 소제목·사진·여백만으로 구분이 충분하거나 선을 넣어 사진과 설명이 떨어지는 경우 |
| 인용구: 요약 강조 | 도입 뒤 핵심 관찰 또는 마무리의 선택 기준 | 본문에 근거가 있는 한두 문장을 강조. 짧은 리뷰는 0~1개부터 검토. 작성자의 요약임을 알 수 있게 작성 | 같은 말을 바로 다시 설명하거나 장문·키워드 나열을 넣는 경우 |
| 인용구: 소제목 서식 | 위치·좌석·메뉴 등 구간의 시작 | 사용자가 이 스타일을 원하면 같은 서식으로 일관되게 적용. 일반 소제목과 인용구 소제목을 같은 자리에서 중복하지 않음 | 내용보다 장식이 눈에 띄거나 모바일에서 지나치게 큰 여백이 생기는 경우 |
| 스티커 | 도입 인사 뒤, 실제 감정이 담긴 경험 단락 뒤, 마무리 인사 뒤 | 기본은 생략. 친근한 스타일 요청이면 1~2개를 시작안으로 검토하고 한 세트·비슷한 크기 사용 | 차분한 정보형 글, 가격·주소·협찬 고지 중간, 반복 감탄·움직임으로 읽기가 방해되는 경우 |

구분선·인용구·스티커를 연달아 넣어 같은 전환을 세 번 표시하지 않는다. 사진과 그 사진을 설명하는 문단은 가깝게 유지한다. 넣을 이유가 없으면 세 요소 모두 생략해도 된다.

인용구 컴포넌트는 서식이다. 자신의 요약을 타인의 추천·매장 발언처럼 보이게 만들지 않는다. 실제 타인의 말을 인용할 때는 출처를 표시하고 허용 범위 안에서 짧게 인용한다. 다른 블로그의 고유 문구·스티커 이미지·구분선 디자인을 복제하지 않는다.

스티커는 현재 편집기에서 사용 가능한 기본·무료·보유 항목 중 선택한다. 유료 구매·구독은 별도 요청 없이 진행하지 않는다. 스티커의 “최고”, “내돈내산”, “협찬” 문구도 실제 확인 사실과 일치해야 하며, 협찬 고지나 중요한 정보의 본문 텍스트를 대신할 수 없다. 사용 가능한 항목을 확인하지 못했으면 정확한 상품명·보유 여부를 지어내지 않고 선택 조건으로 남긴다.

## 편집 구성안과 전달

[에디터 규격](editor-components.md)의 고유 블록 ID로 위치를 지정한다. 각 장식에는 목적·역할·스타일·대체 방법을 비공개 구성안에 적는다. 인용구의 실제 문장은 깨끗한 게시 본문에도 포함하고, 서식 지시·스티커 선택 조건은 공개 본문에서 제외한다.

```text
[블록:D01 | 구분선 | 스타일:단순선 | 목적:경험에서방문정보로전환]
[블록:Q01 | 인용구 | 역할:작성자요약 | 스타일:단순형] 제가 방문한 오후에는 큰 테이블에서 작업하기 편했어요.
[블록:S01 | 스티커 | 목적:마무리인사 | 선택:기본·무료·보유항목중차분한인사 | 미지원:생략]
```

publisher는 현재 화면에서 지원하는 서식을 확인한다. 구분선 미지원은 여백, 인용구 미지원은 일반 문단 또는 소제목, 스티커 미지원·선택 미확정은 생략으로 처리하고 차이를 기록한다. 다른 스티커를 임의 구매하거나 외부 이미지를 가져와 대체하지 않는다.

미리보기에서는 선·인용구의 여백과 글자 크기, 스티커의 실제 크기·움직임, 사진 설명과의 거리, 중요한 정보 가독성을 점검한다. 실제 미리보기를 열지 않았다면 설계 검수와 화면 검수를 구분한다.
