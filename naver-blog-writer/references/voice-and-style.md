# 참고 블로그 분석과 문체 설정

## 조사 방법

새 문체 분석을 요청받으면 사용자 지정 글을 우선 읽는다. 지정 글이 없으면 같은 카테고리·검색 의도의 공개 네이버 글을 서로 다른 작성자 기준으로 3~5개 정도 확보한다. 이 수는 문체 비교를 위한 실무 표본이며 SEO 규칙이 아니다. 지정 작성자의 일관된 문체를 판단하려면 여러 글을 확인한다. 적은 표본이면 그 한계를 밝힌다. 기존 프로필이나 명확한 어투 요청만 적용하는 경우 새 조사는 생략한다.

네이버 인플루언서 지위는 공식 프로필 등 근거가 있을 때만 기록한다. 검색에 나온 것, 댓글이 많은 것만으로 인플루언서 또는 상위 노출 성공 사례라고 부르지 않는다.

본문만 분석하고 메뉴·태그·댓글·인용문은 제외한다. 표본마다 URL, 제목, 작성자, 게시일, 확인일, 읽은 범위를 남긴다. 관찰 항목:

- 해요체·합니다체·혼용, 과거형·현재형의 역할
- `-었어요`, `-더라고요`, `-답니다`, `-습니다`, `-죠?` 등 문장 끝맺음
- 문장·문단 길이, 질문·독자 호명, 감탄·웃음·이모지
- 경험 서술과 가격·이용 정보의 구분, 장단점 표현

정량 비율은 직접 센 문장 수와 분류 기준을 제시할 때만 쓴다. 제목만 본 글을 본문 분석에 포함하지 않는다.

## 조사 결과 보관

배포용 문서에는 개인 작성자의 닉네임·계정 URL·고유 글 제목을 넣지 않는다. 실제 조사 기록은 사용자 작업 폴더의 비공개 보고서에 출처와 읽은 범위를 남기고, 공유용 결과에서는 표본 ID로 구분한다. 이 파일은 조사 방법과 편집 기본값이며 개인 표본의 인기·검색 성과를 입증한 보고서가 아니다.

## 문체 프로필

관찰을 사용자 취향·독자 목적과 연결해 다음을 설정한다. 아래 기본값은 편집 제안이며 검증된 검색 공식이 아니다.

| 설정 | 기본값 | 변경 조건 |
| --- | --- | --- |
| 기본 말투 | 차분하고 친근한 해요체 | 사용자 글·요청을 우선 |
| 경험 어미 | `-었어요`, 실제 발견에만 `-더라고요` | 정보형 글은 경험을 지어내지 않음 |
| 정보 전달 | 간결한 설명 + 출처·시점 | 사실 전달 때문에 갑자기 딱딱한 말투로 바꾸지 않음 |
| 문단 | 한 질문·관찰당 짧은 단락 | 모바일 가독성에 맞춰 조절 |
| 감탄·이모지 | 적게, 선택적으로 | 사용자가 원하는 친근함에 맞춤 |
| 추천 | 어떤 사람에게 맞는지 조건부 설명 | 무조건·최고·인생 같은 단정은 근거 없이 쓰지 않음 |

분석 결과는 `관찰 → 선택한 설정 → 이유`로 짧게 제시한다. 동일한 확인 사실을 담은 짧은 샘플 문단을 써보고 본문 전체에 적용한다. 원문 긴 인용이나 문장 바꿔 쓰기로 스타일을 구현하지 않는다.
