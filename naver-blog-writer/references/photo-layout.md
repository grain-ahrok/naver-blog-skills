# 사진 선택·배치

사진은 독자의 질문에 답하는 증거와 안내 자료로 배치한다. 아래 구성을 실무 편집 기본값으로 사용하며 사진 수·간격이 검색 순위를 높인다고 주장하지 않는다.

## 확인

실제 파일을 열어 무엇이 보이는지 확인한다. 파일명만 보고 내용·맛·청결·성능을 추정하지 않는다. 첨부 수와 종류를 기록하고 식별자가 유지되도록 `P01` 등 사진 ID와 원래 파일명을 연결한다. 제공받은 사진은 기본적으로 모두 배치 대상으로 삼고, 비슷하다는 이유만으로 임의 제외하지 않는다. 제외가 필요하면 사진 ID·이유와 대안을 먼저 확인한다. 개인정보·권리 문제가 미해결인 사진은 이유를 알리고 보류한다. 사진이 없으면 원고와 촬영 목록을 만들 수 있지만 사진을 보유했다고 하지 않는다.

## 배치 기본안

| 구간 | 사진 역할 | 선택 기준 |
| --- | --- | --- |
| 도입 | 대표 사진 1장 | 글의 핵심 경험·대상을 가장 잘 보여주는 사진 |
| 위치·방문 | 외관·입구·동선 | 찾아가기 정보가 중요한 경우 |
| 선택·가격 | 메뉴판·주문·구매 내역 | 글에서 다룬 가격·구성을 확인할 수 있을 때 |
| 핵심 경험 | 음식·좌석·객실·제품 사용 | 관련 설명 앞뒤에 배치하고 가까운 본문에서 해설 |
| 비교·주의 | 크기·구성·차이·불편 요소 | 장단점 이해에 도움이 되고 실제 사진이 있을 때 |
| 마무리 | 선택적 전경·결과 | 새로운 정보가 있을 때만, 같은 사진 반복 제외 |

짧은 리뷰의 시작안은 대표 1장, 핵심 정보 2~4장, 세부 경험 1~3장 정도다. 장문·여행 동선은 소제목마다 필요한 사진 묶음을 설계한다. 이 범위는 편집 제안이며 부족한 사진을 억지로 채우거나 제공된 사진을 범위에 맞춰 삭제하지 않는다. 많은 사진은 관련 사진을 묶고, 적은 사진은 핵심 정보를 먼저 설명한다.

모바일에서는 설명 없이 비슷한 사진을 길게 이어 붙이지 않는다. 하나의 정보 묶음에 필요한 사진 1~3장과 짧은 설명을 시작안으로 삼되 실제 화면에서 조절한다. 메뉴판은 가격이 읽히는 크기로, 비교 사진은 가능하면 같은 각도·조건으로 배치한다. 원본과 게시 미리보기에서 잘림·가독성을 확인한다. 텍스트의 모든 줄을 인위적으로 짧게 끊지는 않는다.

## 공개 글 참고 조사

사진 구성을 조사할 때는 현재 소재·검색 의도에 맞는 공개 글을 선택한다. 사진·본문 순서가 실제로 보이면 대표 사진, 정보 사진, 경험 사진, 캡션, 사진 사이 설명을 기록한다. 이미지 링크 목록만 읽힌 경우 실제 화면의 크기·간격·총 배치 수를 확인했다고 하지 않는다. 개인 계정 URL·글 제목은 배포 문서에 넣지 않고 실제 출처는 비공개 조사 기록에 남긴다. 위 숫자 범위는 표본에서 측정한 값이 아닌 편집 시작안이다.

## 레이아웃과 배치표

[에디터 구성 규격](editor-components.md)에 따라 정보 묶음을 개별·콜라주·슬라이드에 연결한다. 문단 번호 대신 고유 블록 ID로 사진 위치를 연결한다.

비슷한 외관·굿즈·쇼케이스·비교 사진은 2~3장씩 가로 콜라주로 묶는 것을 시작안으로 삼는다. 같은 역할·비슷한 비율의 사진끼리 묶고, 원본 파일을 합성하기보다 네이버의 그룹 사진·콜라주 기능을 우선한다. 대표 사진·핵심 좌석 사진은 단독 배치를 고려한다. 메뉴·가격·세부 글자를 읽어야 하는 사진은 모바일에서 작아지면 개별 사진으로 유지하거나 별도 확대 사진을 병행한다. 임의로 자르거나 중요한 부분을 숨기지 않는다. 구성안에는 사진 ID·순서·가로 열 수·잘림 허용 여부와 미지원 시 개별 배치 대안을 적는다. 배치 변경은 사진 제외 승인이 아니다.

## 배치표와 검수

`사진 ID / 게시용 파일 절대 경로 / 편집 블록 ID·레이아웃 / 역할 / 캡션 / 검수 상태`를 출력한다. 캡션은 사진에 보이는 사실과 사용자가 알려준 경험만 담는다. 파일을 실제 가공하지 않았다면 가공했다고 하지 않는다. 사진 ID와 원본의 대응은 비공개 작업 자료에만 보관한다.

얼굴·차량번호·영수증 개인정보·화면 계정정보가 있으면 가림 필요를 표시한다. 남의 블로그 사진은 가져오지 않고 사용 권한이 확인된 자료만 쓴다. AI 이미지가 요청되더라도 실제 방문·구매 증거처럼 제시하지 않는다. 사용자의 공개 범위 밖 자료는 자동 업로드하지 않는다.
