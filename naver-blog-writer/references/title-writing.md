# 리뷰 제목 조사와 작성

## 참고 제목 조사

사용자가 다른 블로그의 제목을 조사해 달라고 하면 같은 소재·지역·검색 의도의 공개 네이버 글을 우선 비교한다. 서로 다른 작성자의 표본 3~5개를 시작안으로 삼되, 부족하면 확보한 수와 범위를 밝힌다. 인접 업종이나 다른 지역 사례는 구분한다. 최신 트렌드라고 단정하거나 검색 결과만으로 인기·검색 성과·인플루언서 지위를 추정하지 않는다.

제목, URL, 게시일, 확인일, 읽은 범위를 비공개 조사 기록에 남긴다. 검색 결과 제목만 확인했으면 그 범위를 명시한다. 본문을 확인했다면 제목의 메뉴·경험·정보가 실제 본문에 있는지도 대조한다. 다른 글의 가격·맛·방문 경험은 사용자의 원고로 옮기지 않는다. 배포용 스킬에는 개인 계정·닉네임·고유 제목을 기록하지 않는다.

표본에서 다음을 관찰하고 `관찰 → 이번 글의 선택 → 이유`로 요약한다.

- 지역·상호·메뉴를 어떤 순서로 배치했는가
- 메뉴 후기, 방문 상황, 이용 정보 중 무엇을 제목의 초점으로 골랐는가
- 괄호·쉼표·구분 기호가 정보 구분에 필요한가
- 비슷한 지역 키워드, 형용사, 홍보 표현이 중복되는가

## 제목 선택

지역과 상호가 필요한 리뷰에는 그 정보를 앞부분에서 알아볼 수 있게 쓰고, 확인된 메뉴 또는 경험 하나를 덧붙인다. 모든 글에 동일한 공식을 강제하지 않는다. 짧은 일상 기록은 자연스러운 문장형도 가능하다. 맛·분위기·친절함 등 본문 전체의 장점을 한 제목에 열거하지 않는다.

기본 후보는 서로 다른 초점으로 제시한다.

| 유형 | 구성 예시(가상의 상호) | 적합한 본문 |
| --- | --- | --- |
| 메뉴 중심 | 성수 가온식당, 오리지널·오징어 텐동 후기 | 실제 먹은 메뉴와 차이가 중심 |
| 경험 중심 | 성수 가온식당, 담백한 튀김이 기억에 남은 저녁 | 사용자가 확인한 맛 경험이 중심 |
| 정보 중심 | 성수 가온식당 내돈내산 후기, 메뉴와 가격 | 직접 결제와 방문 당시 정보가 확인됨 |

추천안을 하나 고르고 이유를 짧게 쓴다. 제목에 넣지 못한 분위기·좌석·친절함은 도입이나 소제목에 남긴다. 사용자가 제목을 촌스럽거나 광고 같다고 하면 형용사와 장점 나열을 줄이고, 상호·메뉴·직접 경험처럼 구체적인 말로 다시 쓴다. 이 취향은 현재 작업의 선호로 기록하고 모든 사용자에게 강제하지 않는다.

`숨은 맛집`, `인생 텐동`, `무조건 추천`, `데이트 성공` 같은 근거 없는 표현을 추가하지 않는다. 직접 결제 확인 없이 `내돈내산`, 두 번째 방문 확인 없이 `또간집`, 실제 대기 경험 없이 `웨이팅`을 넣지 않는다. 경제적 대가가 있다면 협찬 지침을 우선한다. 쉼표나 구분 기호는 필요할 때만 사용하고 이모지·괄호·기호를 장식용으로 겹치지 않는다.

소리 내어 읽었을 때 자연스러운지, 본문과 일치하는지, 핵심 정보가 모바일 미리보기에서 보이는지 확인한다. 고정 글자 수·키워드 횟수·기호를 검색 노출 보장 기준으로 설명하지 않는다. 조사 표본에서 발견한 방식과 편집자가 제안한 개선안을 구분한다.
